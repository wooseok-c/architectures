# Swin Transformer 정리

> Liu et al., *Swin Transformer: Hierarchical Vision Transformer using Shifted Windows*, ICCV 2021 (best paper)
> 논문: Liu et al., ICCV 2021

---

## 1. 무슨 문제를 푸는가

ViT는 vision **backbone**이 못 된다. 이유 두 가지:

| 문제 | 내용 | Swin의 처방 |
|---|---|---|
| ① 스케일 고정 | 토큰이 전 층에서 같은 크기 → 다양한 크기의 물체를 못 다룸 | **계층 구조** (patch merging) |
| ② 제곱 복잡도 | attention 비용이 토큰 수의 제곱 → 고해상도 불가 | **윈도우 내부 attention** |

그리고 ②의 부작용(윈도우가 갇힘)을 **shift**로 해결한다.

## 2. 핵심 아이디어 — 교실 비유

패치 = 학생, 윈도우 = 조, 층 = 교시. **같은 조끼리만 대화 가능.**

### ① W-MSA — 조 나누기

전원이 대화하면 3,136² 칸짜리 표. 49명씩 64개 조로 나누면 49²짜리 표 64개.

```
전역   : 3,136 × 3,136 = 9,834,496
윈도우 :    49 ×    49 × 64개 =  153,664     64배 절감 (= 조 개수)
```

이미지가 커져도 **조 인원(49)은 고정, 조 개수만 증가** → 비용이 선형.

### ② SW-MSA — 조 다시 짜기

조를 고정하면 소문이 조 안에 영원히 갇힌다. 층마다 경계선을 **절반(3칸)** 씩 민다.

```
1교시: [1 2 3 4][5 6 7 8]     1번 소문이 4번까지
2교시: [1 2][3 4 5 6][7 8]    3번이 5번에게 전달
3교시: [1 2 3 4][5 6 7 8]     5번이 8번에게 → 전역 도달
```

**W-MSA / SW-MSA 는 반드시 2개 한 짝** → 블록 수가 전부 짝수 `{2,2,6,2}`.

구현은 경계선 대신 **격자를 굴린다** (`torch.roll(-3,-3)`). 굴리면 반대편 끝이 넘어와 섞이므로 **마스크**로 그 쌍만 차단.

### ③ Patch Merging — 학생 합치기

**왜 필요한가.** 조 크기가 7×7 로 고정이라, W/SW-MSA 만 반복하면 조 하나가 보는
실제 이미지 면적이 **영원히 28×28 픽셀**이다. 고양이가 100×100 픽셀을 차지하면
어떤 조도 고양이를 통째로 못 본다. shift 로 정보가 퍼지긴 하지만 한 층에 3칸씩이라
56칸을 가로지르려면 층이 20개쯤 필요한데 Swin-T 의 블록은 총 12개뿐이다.
→ **학생을 합쳐서 한 명이 넓은 면적을 대표하게 만든다.**

**어떻게.** 두 단계다.

```
1) concat : 2×2 이웃 4명의 벡터를 그냥 이어붙임   96 → 384  (4배)
2) Linear : 너무 두꺼우니 절반으로 압축           384 → 192  (2배)
```

작은 예 (학생 16명, 각자 숫자 2개):

```
a=[1,2] b=[3,4]          concat        Linear(8→4)
c=[5,6] d=[7,8]   ──▶  [1,2,3,4,5,6,7,8]  ──▶  [?,?,?,?]

학생 16명 → 4명 (1/4)    숫자 2개 → 4개 (2배)
```

**세 문구의 뜻:**

| 문구 | 뜻 | 위 예 | 실제 Swin |
|---|---|---|---|
| 학생 1/4 | 2×2 묶으니 4명이 1명 | 16 → 4명 | 3,136 → 784명 |
| 채널 2배 | 한 명이 든 숫자 개수 | 2 → 4개 | 96 → 192개 |
| 데이터량 절반 | 학생 수 × 숫자 개수 | 32 → 16 | 301,056 → 150,528 |

```
합치기 전:  16명 × 2개 = 32      concat 후: 4명 × 8개 = 32   ← 똑같음, 정보 보존
                                 Linear 후: 4명 × 4개 = 16   ← 절반
```

**concat 은 총량을 안 바꾼다** (자리만 합침). 압축하는 건 Linear 이고,
무엇을 남길지는 학습으로 정한다. pooling 처럼 버리지 않는 게 장점.

**왜 384 를 그대로 안 두나:** 안 줄이면 96 → 384 → 1536 → 6144 로 폭발한다.
attention 비용이 채널의 제곱에 비례해서 Stage 4 에서 터진다.

**얻는 것:** 조 크기는 계속 7×7 인데 보는 넓이가 64배 커진다.

```
Stage 1: 학생 1명 =  4×4 픽셀  →  조가 보는 범위  28×28
Stage 4: 학생 1명 = 32×32 픽셀 →                 224×224 (전체)
```

행·열 각각 절반이 되므로 격자는 56 → 28 → 14 → 7.

### ④ Relative Position Bias

attention은 위치를 모른다. **상대 위치**에 따른 보정값을 점수에 더한다.

```
점수 = Q·Kᵀ/√d + B
```

- head마다 따로 존재
- 상대 위치 범위가 `-6 ~ +6` (두 축) → 표 크기 `13×13 = 169`
- 실제 `B`는 `49×49`지만 169개 값을 공유
- ViT의 absolute 방식과 달리 **이동 불변성**이 있음 → dense task에서 유리
- 논문 §4.4: absolute 를 추가하면 검출/분할 성능이 **떨어진다** → 안 씀

## 3. 전체 흐름 (Swin-T, 224×224)

```
(224, 224, 3)
   │ Patch Partition  4×4 픽셀 → 토큰 1개
   ▼
(56, 56, 48)
   │ Linear Embedding 48→96, LN
   ▼
━━ Stage 1 ━━ (56, 56, 96)    조 64개, head 3
   │ 블록 ×2  (W, SW)
   │ Patch Merging → 192
   ▼
━━ Stage 2 ━━ (28, 28, 192)   조 16개, head 6
   │ 블록 ×2
   │ Patch Merging → 384
   ▼
━━ Stage 3 ━━ (14, 14, 384)   조 4개, head 12
   │ 블록 ×6
   │ Patch Merging → 768
   ▼
━━ Stage 4 ━━ (7, 7, 768)     조 1개 = 전역!, head 24
   │ 블록 ×2
   ▼
LayerNorm → mean(dim=1) → (768,) → Linear(768,1000) → logits
```

**격자는 줄고(56→7), 채널과 시야는 늘어난다(96→768).**

| | Stage 1 | Stage 2 | Stage 3 | Stage 4 |
|---|---|---|---|---|
| 격자 | 56×56 | 28×28 | 14×14 | 7×7 |
| 채널 | 96 | 192 | 384 | 768 |
| head | 3 | 6 | 12 | 24 |
| 조 개수 | 64 | 16 | 4 | **1** |
| 조가 보는 원본 면적 | 28² | 56² | 112² | **224² (전체)** |

**head당 차원은 항상 32** (96/3 = 192/6 = 384/12 = 768/24).

## 4. 블록 내부

```
z ─────────────────────┐
LN                     │
(S)W-MSA               │ residual
⊕ ←────────────────────┘
│
├──────────────────────┐
LN                     │
MLP (C → 4C → C, GELU) │ residual
⊕ ←────────────────────┘
z'
```

**MSA 부분만 Swin의 발명.** LN(pre-norm), MLP, residual 은 표준 Transformer 그대로.

### W-MSA 내부

```
(56, 56, 96)
  window_partition   (64, 49, 96)
  Q·Kᵀ/√d + B        (64, 3, 49, 49)
  softmax → @V       (64, 49, 96)
  window_reverse     (56, 56, 96)
```

### SW-MSA = W-MSA + roll 2줄 + mask

```python
x = torch.roll(x, (-s, -s), dims=(1, 2))     # 굴리기
... W-MSA 와 동일, 단 attention 에 mask 추가 ...
x = torch.roll(x, (+s, +s), dims=(1, 2))     # 원위치
```

### 마스크 만들기

```
1. 굴린 격자를 9개 지역으로 나눠 번호 칠하기   (3덩이 × 3덩이)
   slices = (slice(0,-M), slice(-M,-s), slice(-s,None))
2. 같은 window_partition 으로 자르기
3. 조 안에서 번호끼리 빼기 → 0 이면 같은 지역
4. 0 아닌 자리에 -100
5. attention 점수에 더하기 → softmax 에서 0
```

**마스크는 위치에만 의존** → 모델 생성 시 한 번 계산해 `register_buffer` 로 저장. W-MSA 는 마스크 없음(`None`).

## 5. 상수 정리

```
patch 크기        4×4
window M          7          (전 stage 고정)
shift s           M//2 = 3
C                 96         (Swin-T)
블록 수           {2, 2, 6, 2}
head 수           {3, 6, 12, 24}
head 당 차원      32         (항상)
MLP 확장률        4배
LN                pre-norm (모듈 앞에)
분류              LN → mean(dim=1) → Linear(768, 1000)
```

변종: **T**(C=96, {2,2,6,2}) / **S**(C=96, {2,2,18,2}) / **B**(C=128) / **L**(C=192)

## 6. ResNet 과의 관계 (헷갈리기 쉬움)

세 가지가 **별개**다.

| | 무엇 | 출처 |
|---|---|---|
| residual connection | 블록 안의 `+ z` | **원조 Transformer**. ResNet 기원이지만 Swin이 직접 가져온 건 아님 |
| **4-stage 해상도 규격** | 56/28/14/7 | **ResNet 모방.** backbone 교체 호환성이 목적 ← **이게 진짜 연결점** |
| receptive field 논리 | 국소 연산을 쌓으면 시야가 넓어짐 | **CNN 일반**. ResNet 특유가 아님 |

**backbone 교체**란:

```python
backbone = ResNet50()                              # 원래
backbone = SwinTransformer()                       # 교체
fpn = FPN(in_channels=[96, 192, 384, 768])         # 채널 숫자만 수정
```

FPN 은 backbone 이 1/4, 1/8, 1/16, 1/32 네 해상도를 준다고 가정하고 짜여 있다.
ViT 는 1/16 하나뿐이라 못 끼운다. Swin 은 규격을 맞춰서 그대로 들어간다.

**Swin 이 FPN 을 요구하는 게 아니라, 기존 생태계 규격에 자기를 맞춘 것.** 분류할 때는 FPN 이 아예 없다.

## 7. 구현 체크리스트

```
[x] window_partition / window_reverse      → window_ops.py
[ ] WindowAttention   (Q,K,V + relative position bias + mask)
[ ] SwinBlock         (attn + MLP + residual + roll)
[ ] PatchMerging
[ ] PatchEmbed        (Conv2d(3, 96, k=4, s=4) 로 한 방에)
[ ] SwinTransformer   (전체 조립 + 분류 head)
```

### 흔한 함정

- `permute` 뒤에 `view` 를 쓰려면 `.contiguous()` 필요 (`reshape` 은 알아서 해줌)
- 블록 수는 **짝수** — W/SW 가 짝을 이뤄야 함
- 마스크는 **SW-MSA 에만**. W-MSA 는 `None`
- LN 은 **pre-norm** (모듈 앞)
- 검증: `sum(p.numel() for p in model.parameters())` 가 논문 Table 1 의 **28~29M** 근처인지

### 안 해도 되는 것

FPN, box/mask head, 검출 파이프라인 — Swin 논문 범위 밖 (Mask R-CNN 영역).
**"이미지 → 클래스 점수 1000개"** 까지가 목표.
